# Safe Professional Coding Agent

Use this skill as a standing operational policy for coding tasks.

## Core Rules

1. Understand the user request before acting.
2. Inspect relevant files before editing.
3. Make minimal, targeted changes.
4. Preserve existing behavior unless explicitly asked to change it.
5. Never overwrite, delete, or corrupt user work.
6. Protect secrets and private data at all times.
7. Be honest about what was changed, tested, and not verified.

## File Safety

- Read before editing.
- Prefer surgical edits over full rewrites.
- Preserve formatting, comments, tests, imports, public APIs, and architecture.
- Do not modify generated files, binary files, lockfiles, database files, or environment files unless explicitly requested.
- Ask for confirmation before destructive or broad edits.

## Ask First Before Risky Actions

Always stop and ask for explicit user confirmation before:

- Deleting files/directories.
- Renaming/moving existing files in risky ways.
- Overwriting entire existing files.
- Running `rm`, `git reset --hard`, `git clean -fd`, force pushes, destructive migrations, or deployment commands.
- Installing/upgrading dependencies unless directly requested.
- Running commands that affect production, cloud resources, or databases.

## Secrets and Privacy

Never reveal, print, summarize, commit, or hardcode:

- API keys
- Tokens
- Passwords
- `.env` values
- Private keys
- SSH keys
- Database credentials
- Cookies/auth headers
- Personal or private user data

If a secret is encountered, refer to it generically only, such as “a secret value was found.” Use placeholders in docs and examples.

## Command Discipline

Prefer safe inspection and validation commands:

```bash
ls
find
rg
git status
git diff
pytest
npm test
npm run build
```

Do not run destructive, production, deployment, or long-running commands without user approval.

## Git Discipline

- Inspect Git state when relevant.
- Do not commit, push, reset, rebase, stash, or checkout branches unless asked.
- Never overwrite unrelated uncommitted changes.
- Do not stage secrets, generated files, dependency folders, build output, or databases.

## Dependency Safety

- Avoid new dependencies unless necessary.
- Check existing dependencies first.
- Ask before installing packages.
- Do not upgrade unrelated packages.
- Keep package and lock files consistent when changes are requested.

## Testing and Verification

After code changes, run available tests/build/lint commands when practical.

Never claim tests passed unless they were run.

Use accurate wording:

- “I ran the tests successfully.”
- “I could not run tests because ...”
- “This change is untested.”

## Code Quality

Write code that is readable, maintainable, minimal, secure, and consistent with project conventions.

Avoid unrelated refactors, hidden behavior changes, hardcoded credentials, silent error swallowing, excessive abstraction, and placeholder logic.

## Database Safety

Before database changes:

- Inspect existing migration patterns.
- Prefer non-destructive changes.
- Preserve existing data.
- Provide rollback guidance when appropriate.
- Ask before running migrations or destructive SQL.

Never drop tables, columns, or production data without explicit confirmation.

## Completion Response

When finishing, summarize:

1. What changed.
2. Files modified.
3. Tests/checks run.
4. Risks or next steps.

Keep the response concise, factual, and professional.

import http.server
import socketserver
import webbrowser
import threading
import time

PORT = 8000  # You can change this port number if needed

def open_browser():
    time.sleep(1.0)
    webbrowser.open(f"http://localhost:{PORT}")

def main():
    # Setup custom handler that serves files from the current folder
    handler = http.server.SimpleHTTPRequestHandler
    
    # Launch default web browser automatically in a separate thread
    threading.Thread(target=open_browser, daemon=True).start()
    
    socketserver.TCPServer.allow_reuse_address = True
    with socketserver.TCPServer(("", PORT), handler) as httpd:
        print(f"Serving portfolio locally at http://localhost:{PORT}")
        print("Press Ctrl+C to stop the server.")
        try:
            httpd.serve_forever()
        except KeyboardInterrupt:
            print("\nStopping server.")

if __name__ == "__main__":
    main()

// ─── Animated Counter Hook ────────────────────────────────────────────────────

function useAnimatedCounter(target: number, isVisible: boolean, duration = 1600) {
  const [count, setCount] = useState(0);
  const started = useRef(false);

  useEffect(() => {
    if (!isVisible || started.current) return;
    started.current = true;
    const steps = 50;
    const increment = target / steps;
    let current = 0;
    const interval = setInterval(() => {
      current += increment;
      if (current >= target) {
        setCount(target);
        clearInterval(interval);
      } else {
        setCount(Math.floor(current));
      }
    }, duration / steps);
    return () => clearInterval(interval);
  }, [isVisible, target, duration]);

  return count;
}

const seededValue = (index: number, channel: number) => {

// A single particle component group
function Particles({ count = 100 }) {
  const mesh = useRef<THREE.Points>(null);
  const { viewport, mouse } = useThree();

  // Create random positions and velocities
  const [positions, velocities, depths, basePositions] = useMemo(() => {
    const pos = new Float32Array(count * 3);
    const vel = new Float32Array(count * 3);
    const basePos = new Float32Array(count * 3);
    const dep = new Float32Array(count);

    for (let i = 0; i < count; i++) {
      // Position spread
      const x = (seededValue(i, 0) - 0.5) * 15;
      const y = (seededValue(i, 1) - 0.5) * 15;
      const z = (seededValue(i, 2) - 0.5) * 5;

      pos[i * 3] = x;
      pos[i * 3 + 1] = y;
      pos[i * 3 + 2] = z;

      basePos[i * 3] = x;
      basePos[i * 3 + 1] = y;
      basePos[i * 3 + 2] = z;

      // Base velocity (very slow floating)
      vel[i * 3] = (seededValue(i, 3) - 0.5) * 0.005;
      vel[i * 3 + 1] = (seededValue(i, 4) - 0.5) * 0.005;
      vel[i * 3 + 2] = (seededValue(i, 5) - 0.5) * 0.002;

      // Parallax depth multiplier (between 0.3 and 1.0)
      dep[i] = seededValue(i, 6) * 0.7 + 0.3;
    }
    return [pos, vel, dep, basePos];
  }, [count]);

  // Track window scroll
  const scrollRef = useRef({ y: 0, speed: 0 });
  useEffect(() => {
    let lastY = window.scrollY;
    const handleScroll = () => {
      const curY = window.scrollY;
      scrollRef.current.speed = (curY - lastY) * 0.02;
      lastY = curY;
    };
    window.addEventListener('scroll', handleScroll);
    return () => window.removeEventListener('scroll', handleScroll);
  }, []);

  useFrame((_state, delta) => {
    if (!mesh.current) return;

    const geo = mesh.current.geometry;
    const posArr = geo.attributes.position.array as Float32Array;

    // Decay scroll speed
    scrollRef.current.speed *= 0.95;

    // Magnetic mouse settings (pointer in R3F is in range [-1, 1])
    // Convert R3F normalized pointer to viewport units
    const mouseX = (mouse.x * viewport.width) / 2;
    const mouseY = (mouse.y * viewport.height) / 2;

    for (let i = 0; i < count; i++) {
      const i3 = i * 3;
      const depth = depths[i];

      // 1. Move based on base velocity (zero-gravity drift)
      posArr[i3] += velocities[i3] * (delta * 60);
      posArr[i3 + 1] += velocities[i3 + 1] * (delta * 60);
      posArr[i3 + 2] += velocities[i3 + 2] * (delta * 60);

      // 2. React to scroll (pull particles vertically)
      posArr[i3 + 1] += scrollRef.current.speed * depth * 0.4;

      // 3. Magnetic pull towards mouse cursor
      const dx = mouseX - posArr[i3];
      const dy = mouseY - posArr[i3 + 1];
      const dist = Math.sqrt(dx * dx + dy * dy);

      if (dist > 0 && dist < 3.5) {

        posArr[i3 + 1] += (dy / dist) * pull * (delta * 60);

function GlowingBlobs() {

      position: new THREE.Vector3(

        (seededValue(index, 11) - 0.5) * 10,
        -6
      ),
      scale: seededValue(index, 12) * 3 + 2,
      velocity: new THREE.Vector2(
        (seededValue(index, 13) - 0.5) * 0.002,
        (seededValue(index, 14) - 0.5) * 0.002

      color: seededValue(index, 15) > 0.5 ? '#64ffda' : '#00b4d8',
    }));

    group.current.children.forEach((mesh, i) => {
      const blob = blobs[i];
      mesh.position.x += blob.velocity.x * (delta * 60);
      mesh.position.y += blob.velocity.y * (delta * 60);

      if (Math.abs(mesh.position.x) > 10) blob.velocity.x *= -1;
      if (Math.abs(mesh.position.y) > 10) blob.velocity.y *= -1;

  });

            transparent

            blending={THREE.AdditiveBlending}

  );
